The firm’s positioning is strong: a partner-led GCC financial-services specialist with Bloomberg airtime and live DIFC and ADGM mandates. The website undersells it. It runs on a stock consulting theme, carries public copy errors, and gives search engines very little to work with.

Check the firewall. From our cloud test browser the HTML loaded, but every image, script and stylesheet returned 403 Forbidden, so the page rendered with broken images and a blank hero. Most visitors on home or office connections will not see this. It will affect some VPN users, some corporate networks, and link-preview bots such as LinkedIn’s. Ask the host to review the LiteSpeed or Imunify rule that blocks /wp-content/.

Findings

Fix this week

Critical

Client names are readable in the public Atlas job feed

The Atlas job board page hides the client, but its public API returns the client company name for all 25 published roles. Anyone who knows where to look can see which firms are hiring for which positions.

Raise it with Atlas this week. See Atlas integration.

Critical

“Ask ChatGPT” is in the homepage title

The page title reads “Cordell Partners is a trusted executive search firm with 14 years of UAE experience … Ask ChatGPT”. It shows in Google results and browser tabs.

Change the title to “Cordell Partners | Executive Search for GCC Financial Services”.

Critical

“SHREK firms” on the Services page

The fee paragraph says commitment fees “will be nowhere near the SHREK firms”. It reads as a typo or an in-joke to a prospective client.

Replace with the fee-model copy in the template.

Critical

Figures that contradict each other

The homepage shows 966 “satisfied clients” beside 315 executed mandates, and “2 focused locations” while the footer lists Dubai, Abu Dhabi and London. Senior buyers notice numbers that do not add up.

Keep only figures you can source. Suggested set: years in the UAE, mandates executed, retained completion rate, offices.

High

Spelling errors in public copy

“soltutions”, “cordell partnes”, “georgraphies”, “juristictions”, “Group bead of Compliance”, “stake holder”, and mandate numbering in mixed case (“one”, “TWO”).

Correct them, and have a second person proofread before anything is published.

Search and sharing

High

No H1 on any page

All five pages rely on H2 and H3 tags. Search engines and screen readers get no main heading.

One H1 per page that states the topic, e.g. “Live executive mandates in DIFC and ADGM”.

High

No meta descriptions or social previews

No meta description and no Open Graph tags on any page. Links shared on LinkedIn, the firm’s main channel, show no controlled image or summary.

Write a description for each page and add a branded 1200×630 share image.

High

No structured data

There is no Organization, LocalBusiness or JobPosting markup, so mandates are not eligible for Google’s job listings.

Add JobPosting markup to every live mandate and Organization markup site-wide.

Medium

Unreadable image names and missing alt text

Files such as WhatsApp-Image-2025-08-15-at-1.45.51-PM.jpeg and Screenshot-2025-08-14-010735.png. There are 44 images with empty alt text across the five pages.

Use descriptive file names and real alt text on meaningful images.

Performance

High

Too much code for a text site

The homepage makes 114 requests: 57 scripts and 43 stylesheets, about 1.9 MB on desktop. The network took 7.3 seconds to go idle in our test.

Remove WooCommerce, The Events Calendar and Slider Revolution. On a rebuild, target under 30 requests and 500 KB.

Brand, trust and conversion

High

The look does not match the market

Violet gradients (#827dfd), rounded icon cards and a stock world map are SaaS conventions. Executive search buyers, such as sovereign funds, boards and family offices, expect editorial restraint, like a private bank or a law firm.

Deep ink and stone palette, a high-contrast serif, a single brass accent, generous space. See the template.

Medium

People are the product, but they are missing

Oscar is named in every testimonial, yet there is no team page, no partner profiles and no photos. Testimonials use first names only.

Add partner profiles with editorial portraits and LinkedIn links. Ask referees to allow full names and firms.

Medium

One generic call to action for two audiences

Clients and candidates both get “Contact us”. Mandates only offer “Apply here”, with no confidential CV route.

Two paths: “Brief us on a search” for clients, “Send your CV in confidence” for candidates. Route both into Atlas.

Low

Insights do not show their sources

Press items do not name the publication, apart from Bloomberg in the body copy.

Show the outlet on each item and link to the original article.

Atlas integration

Cordell already runs a public Atlas job board at my.recruitwithatlas.com/Cordell-Partners/jobs. The website does not link to it and repeats four old mandates instead.

Active projects in Atlas46Every open search, including talent pools and internal projects.
Published on the Atlas board25Each role has a full brief and an application form.
Shown on the website4Typed in by hand and out of date.

How the Atlas board works

PartWhat it is
Job listA public GraphQL API at api.recruitwithatlas.com/public-graphql, queried with the agency alias Cordell-Partners. It needs no key, and it accepts requests from any website.
Job pagemy.recruitwithatlas.com/public/<project id> shows the full job description from Atlas.
Apply formFull name, email, LinkedIn profile, CV (required) and extra files. The application lands in the project’s pipeline in Atlas.
PublishingA role appears once applications are enabled on its Atlas project. Nothing has to change on the website.

Confidentiality risk. The job board page never shows the client, but the API behind it returns the client company name for all 25 published roles. For a firm that runs confidential searches, that is a leak. Ask Atlas to remove the company from the public API, or add a per-project “confidential client” setting. Until then, assume every published role reveals its client. The template’s query never asks for client names.

Clean up the Atlas data first

Once the website reads Atlas directly, every field shows publicly exactly as it is typed.

High

Salary written five different ways

Examples: “35,000”, “35000”, “AED 60,000”, “AED 15,000-22,000 per month” and “$125,000 first-year base + discretionary bonus”. 14 of the 25 have no salary at all. The template only shows a salary that names its currency.

Agree one format, e.g. “AED 45,000 per month + bonus”.

Medium

Missing locations and typos in titles

9 of 25 roles have no location set. The template infers 3 from their titles and marks the other 6 “TBC”. One public title reads “Institutional Sales and Distriution”.

Set the location field on every published project and proofread the titles.

Low

21 active projects are not published

Some are talent pools or internal projects and should stay private. Check the rest: each unpublished open search is a role candidates cannot find.

Review the list once a week in the pipeline meeting.

How to build it

Recommended

Webflow

  • Hosting, SSL and CDN included
  • CMS collections for mandates and insights that consultants can edit
  • Native GSAP interactions for the motion system
  • No plugins to patch

Stay on WordPress

  • Custom block theme built from the template
  • Remove Elementor, Slider Revolution, WooCommerce and Events
  • Mandates as a custom post type
  • Best if an agency already maintains it

Astro + headless CMS

  • Fastest result and full design control
  • Mandates pulled from the Atlas API at build time
  • Needs a developer for every change
